# Personal Reflection
## 17 sept 2026

While working on the Interactive Binary Tree Visualizer, I learned more about how a binary tree can be constructed programmatically using level-order traversal. I implemented the `TreeBuilder` class, which takes a list of values and builds the tree using a queue.

One thing I understood better through this work was how a **FIFO queue** can be used to process nodes level by level. I also got more comfortable with Java Generics, such as using `TreeNode<T>` and `BinaryTree<T>`, which allows the same implementation to work with different data types.

While going through the implementation, I also learned the importance of handling edge cases such as an empty list, a null input, or a null root value. Understanding the time and space complexity of the implementation also helped me connect the code with the concepts discussed in class.

Overall, this part of the project helped me understand binary trees in a more practical way instead of only studying them theoretically. I also became more confident in reading and explaining my own code step by step. As I continue the project, I want to improve the visualizer and understand more clearly how the different components work together.
